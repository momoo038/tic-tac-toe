# Tic-Tac-Toe

A classic Tic-Tac-Toe game built as a project for The Odin Project's web development curriculum.

## Project Overview

Involves building a fully functional and singleplayer Tic-Tac-Toe game, focusing on clean code with console-first approach. 


## Features

* Play against another player on the same screen.
* Clear visual feedback for game state (whose turn, win, draw).
* Reset button to start a new game.
